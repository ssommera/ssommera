| **[liminal-eeg](https://github.com/ssommera/liminal-eeg)** | Predicting experience intensity from EEG. MNE + PyTorch pipeline over 34 subjects; EEGNet and a temporal Transformer benchmarked against a published SVM baseline under leave-one-subject-out CV. |
